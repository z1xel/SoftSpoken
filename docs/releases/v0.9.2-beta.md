# SoftSpoken v0.9.2-beta

A focused update to the existing four-addon release for World of Warcraft Vanilla 1.12-compatible clients.

## What's new

- **World-map lore:** Compact tooltips with eligibility consistent with the lore reader.
- **More interactive places:** 141 static POI positions for 139 existing lore associations across 36 maps. Invisible hitboxes provide a fallback for hover and click without adding icons or overriding recognized native targets.
- **Accurate highlights:** Shared overlay artwork is assigned to its reviewed owner instead of highlighting unrelated locations.
- **Lore panel:** The toggle remains outside the map rather than overlapping its contents.
- **Writings:** Removed the redundant voice-pack download-address button.
- **Installation:** Updated clean-upgrade guidance and refreshed showcase images.

## Scope

The original Places catalog, artwork mappings, four-addon structure, SavedVariables, discovery keys, quest catalogs and voice-pack formats are retained. No consolidated dev architecture, G1–G5 geographical expansion, or WMO-discovery implementation is included.

## Installation

Extract all four folders directly into `Interface\\AddOns`: `SoftSpoken`, `SoftSpoken_Stories`, `SoftSpoken_Places`, and `SoftSpoken_Writings`. Remove or replace the old addon folders before installing; keep your WTF/SavedVariables and separately installed voice packs. Enable ClassicAPI (prefer the latest official release), and enable Load out of date AddOns. Do not mix module versions.

## Validation and known limits

The previous main POI and audio-pack CI runs passed. This candidate must pass its own automated staging and regression runs before publication. The new static coordinates are Octo-derived; live client acceptance, particularly on Turtle/other map variants, has not been completed. Existing native detection takes priority. Audio player/control audit (#66) and the wider real-client acceptance checklist (#55) remain open. This is a beta, not a claim of comprehensive client validation.
