SoftSpoken's search icons use the original Turtle WoW interface artwork:
- UI-SearchBox-Icon.blp
- UI-SearchBox-Clear.blp

Source copies: Otari98/Artisan, Textures/UI-SearchBox-Icon.blp and
Textures/UI-SearchBox-Clear.blp (https://github.com/Otari98/Artisan).
These are Turtle-provided UI textures which are absent from stock WoW 1.12.
Bundled here so the Compendium can render them on other 1.12 clients.
