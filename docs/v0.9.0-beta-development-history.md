## Lasting outcome and architectural boundaries

- **One shared audio engine** handles Stories, Places and Writings through Core sources, native sound handles and a coordinated queue; recordings and content packs remain separately installed.

- **Vanilla visual fidelity** supplies a resizable Compendium, native-looking settings and narration, 1.12-compatible TGA/BLP assets and World Map/quest-log integration.

- **Curated quest data** separates identity/location/chain metadata from stage dialogue and voice-pack availability. Unknown speakers or geographic facts must not be invented merely for presentation.

- **Compatibility contracts** intentionally retain the `VoiceOver` global and older pack metadata keys, plus the addon folder names, saved-variable schemas and supported external APIs, even as internal implementation names change.

- **The `v0.9.0-beta` version** applies to the four addon modules; it must not overwrite independent pack content versions or misrepresent unsupported seek/resume audio behavior.

## Known limitations and decisions not to misrepresent

- This document **does not certify the release**. Existing Lua 5.1/CI tests cannot substitute for actual Vanilla/OctoWoW or Turtle client acceptance, including upgrade testing with existing SavedVariables.

- The **discrepancy-only persistence/reporting policy** is not shipped: the shared dialogue service currently saves resolved nonempty live quest stages, even when text agrees with the static corpus.

- Catalog provenance, unresolved speaker/area/text holds, and **bulk quest-text redistribution/attribution** remain discussed in the [consolidated catalog document](turtle-quest-catalog.md).

- **Player controls** still have an [open acceptance audit (#66)](https://github.com/z1xel/SoftSpoken/issues/66). True seek/resume is unavailable; restart-style replay is deliberate.

- The **staging ZIP workflow** builds a preview artifact without publishing a GitHub release. A public package must be built and verified against its final frozen source revision.

- The `Compendium.lua` generated-source header still mentions an old mixed Forever/Era pipeline; the **curated snapshot** and [catalog maintenance policy](turtle-quest-catalog.md) take precedence over those obsolete regeneration instructions.
