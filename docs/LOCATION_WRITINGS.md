# L9 — Writings geography integration

Static book geography uses spoken_classic/upstreamUiMap content crosswalks for both the zones list and the geographic tail of each from tuple. BookGeography returns canonical locations with legacy map/source keys, separate source methods and source-name indices, and the original type/kind/wide attributes. The source-name table, book IDs, pages, original authored data, voice packs and narration keys are unchanged. Static sources never imply a character discovery.

CurrentDiscoveryLocation reads native player AreaTable evidence (not the displayed map), resolves its canonical region and projects to the unique upstream map where one exists. A child location uses its canonical regional ancestor; cities are distinct from their surrounding zone. Text-only compatibility remains when native evidence is unavailable; an observed unmapped native ID does not fall through. Native-only zones such as Hyjal are resolvable but lack a numeric upstream map key. Until L10 the old numeric persistence contract remains, so such new book observations retain the book discovery but have unknown persisted origin; bag acquisitions there cannot yet store a verified origin. No fabricated map IDs or continent-level substitutions.

ObservedLocations groups only verified equivalent persisted map keys, exposing method sets as a read projection. AcquisitionLocations similarly sums distinct outstanding counters for equivalent locations without rewriting them. Unmapped legacy keys remain held and unchanged. RecordBookLocation and carried-book credit preserve the existing observed-only policy, bag baseline, bank exclusion, count decreases, silent discovery and opt-out rules. Persistence tables keep their legacy shape; canonical-key migration and multi-method writes belong to L10.

Readables uses the same static and observed projections, registry names and continent ancestry, and retains the existing city nesting presentation. Per-location discovered flags are no longer allowed to fall back to global found status when a specific location is not found. The narrator continues to use the same discovery summary as the Compendium. Wide/unknown groups, page ordering, type browsing, and source formatting remain.

The full-corpus regression tests all 399 static entries and each geographic reference, source rows, category membership, native scope isolation, genuine world observations, bag acquisition provenance, unknown origins, and no map side effects. Existing narrator and audio tests run alongside it. Live verification belongs to L11.
